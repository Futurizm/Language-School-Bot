## 1. Структура проекта

```
📁 language_school_bot/     ← папка с ботом
    ├── bot.py              ← основная логика бота
    ├── crm.py              ← интеграция с TwentyCRM
    ├── run.py              ← точка входа (загружает .env)
    ├── requirements.txt    ← зависимости Python
    └── .env                ← ваши секреты (токен, API-ключ)

📁 twenty/                  ← папка с Docker для CRM
    ├── docker-compose.yml
    └── .env                ← секреты TwentyCRM (APP_SECRET и др.)
```

> ⚠️ Это **два разных** `.env` файла в разных папках. Не перепутайте их.

## 2. Установка Python и зависимостей

### Требования
- Python 3.10 или новее → [python.org](https://python.org)
- pip (устанавливается вместе с Python)

### Установка

```bash
# Перейдите в папку с ботом
cd language_school_bot

# Создайте виртуальное окружение (рекомендуется)
python -m venv venv

# Активируйте окружение:
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

## 3. Создание Telegram-бота

### Получение токена у @BotFather

1. Откройте Telegram и найдите **@BotFather**
2. Напишите `/newbot`
3. Придумайте **название** (отображаемое имя), например: `Lingo School`
4. Придумайте **username** — должен оканчиваться на `bot`, например: `lingo_school_bot`
5. BotFather выдаст токен вида:
   ```
   1234567890:ABCdefGhijKLmnoPQRstuVWXyz
   ```
6. Скопируйте его — он понадобится в `.env`

> 🔒 Токен — это секрет. Не публикуйте его в GitHub и не пересылайте.

## 4. Запуск TwentyCRM через Docker

### Требования
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) установлен и запущен

### Шаг 1 — Создайте папку и скачайте файлы

```bash
mkdir twenty && cd twenty

# Скачать docker-compose.yml
curl -o docker-compose.yml https://raw.githubusercontent.com/twentyhq/twenty/main/packages/twenty-docker/docker-compose.yml

# Скачать шаблон .env
curl -o .env https://raw.githubusercontent.com/twentyhq/twenty/main/packages/twenty-docker/.env.example
```

### Шаг 2 — Сгенерируйте APP_SECRET

**Windows (PowerShell):**
```powershell
[System.Convert]::ToBase64String([System.Security.Cryptography.RandomNumberGenerator]::GetBytes(32))
```

**macOS / Linux:**
```bash
openssl rand -base64 32
```

### Шаг 3 — Заполните `.env` для TwentyCRM

Откройте файл `twenty/.env` и заполните обязательные поля:

```env
APP_SECRET=сюда_вставьте_сгенерированную_строку

POSTGRES_ADMIN_PASSWORD=придумайте_пароль

SERVER_URL=http://localhost:3000
STORAGE_TYPE=local
```

### Шаг 4 — Запустите контейнеры

```bash
# Сначала поднимите БД и Redis
docker compose up -d db redis

# Подождите 10 секунд, затем запустите миграции
docker compose run --rm server yarn database:migrate:prod

# Запустите всё
docker compose up -d
```

### Шаг 5 — Проверьте статус

```bash
docker compose ps
```

Все контейнеры должны показывать статус `healthy`:

```
NAME              STATUS
twenty-db-1       Up (healthy)
twenty-redis-1    Up (healthy)
twenty-server-1   Up (healthy)
twenty-worker-1   Up
```

### Шаг 6 — Откройте в браузере

Перейдите на **http://localhost:3000**

При первом входе создайте аккаунт администратора.

## 5. Подключение бота к TwentyCRM

### Получение API-ключа

1. Откройте **http://localhost:3000**
2. Перейдите: **Settings → API & Webhooks**
3. Нажмите **+ Create key**
4. Дайте название, например: `Telegram Bot`
5. Скопируйте ключ — он выглядит примерно так:
   ```
   eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   ```

> ⚠️ Ключ показывается **один раз**. Сразу скопируйте и сохраните.

## 6. Настройка .env и запуск бота

Откройте файл `language_school_bot/.env` и заполните:

```env
# Токен от @BotFather
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGhijKLmnoPQRstuVWXyz

# TwentyCRM — локальный Docker-контейнер
TWENTY_API_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
TWENTY_API_URL=http://localhost:3000
```

### Запуск бота

```bash
# Убедитесь что вы в папке language_school_bot
# и виртуальное окружение активировано

python run.py
```

Вы увидите:
```
🤖 Бот запущен! Нажмите Ctrl+C для остановки.
```

Найдите вашего бота в Telegram по username и напишите `/start`.

### Остановка бота

Нажмите **Ctrl + C** в терминале.

## 8. Что попадает в CRM

При каждой заявке в TwentyCRM автоматически создаётся:

### Person (Контакт)
| Поле | Значение |
|------|----------|
| Имя | Из анкеты |
| Фамилия | Из анкеты (если указана) |
| Телефон | Из анкеты |

### Opportunity (Лид)
| Поле | Значение |
|------|----------|
| Название | `[Telegram] Имя — Язык` |
| Статус | `NEW` |
| Валюта | KZT |
| Привязан к | Person (контакт) |

### Note (Заметка)
```
📱 Телефон: +7 777 000 00 00
🌍 Язык: Английский
📊 Уровень: B1-B2
📋 Формат: Мини-группа
💬 Telegram ID: 123456789
🔗 Telegram: @username
📍 Источник: Telegram Bot
```

### Где смотреть в CRM

- **Лиды:** Opportunities → фильтр Stage = NEW
- **Контакты:** People
- **Заметки:** открыть Opportunity → вкладка Notes

## 9. Частые ошибки и решения

### ❌ `TELEGRAM_BOT_TOKEN не задан`
Проверьте файл `language_school_bot/.env` — токен должен быть без пробелов и кавычек.

### ❌ `twenty-server-1 unhealthy`
```bash
# Посмотрите логи
docker compose logs server --tail=30

# Чаще всего помогает полный сброс:
docker compose down -v
docker compose up -d db redis
docker compose run --rm server yarn database:migrate:prod
docker compose up -d
```

### ❌ `Config variables validation failed` / `SERVER_URL must be a URL`
Добавьте в `twenty/.env`:
```env
SERVER_URL=http://localhost:3000
STORAGE_TYPE=local
```

### ❌ `relation "core.workspace" does not exist`
Миграции не применились. Запустите:
```bash
docker compose run --rm server yarn database:migrate:prod
docker compose restart server
```

### ❌ `TWENTY_API_KEY не задан` (в логах бота)
Бот работает, но данные не попадают в CRM. Получите ключ в TwentyCRM (Settings → API & Webhooks) и добавьте в `language_school_bot/.env`.

### ❌ `Не удалось подключиться к TwentyCRM`
Проверьте что Docker-контейнеры запущены:
```bash
docker compose ps
```
Все должны быть `healthy`. Если нет — `docker compose up -d`.

## 10. Кастомизация под вашу школу

Все настройки находятся в файле `bot.py`.

### Изменить языки

```python
LANGUAGES = {
    "🇬🇧 Английский": "Английский",
    "🇩🇪 Немецкий": "Немецкий",
    # Добавьте или удалите языки здесь
}
```

### Изменить уровни

```python
LEVELS = {
    "🟢 Начинающий (A1–A2)": "A1-A2",
    "🟡 Средний (B1–B2)": "B1-B2",
    # ...
}
```

### Изменить контакты и информацию о школе

Найдите в `bot.py` переменные `COURSES_INFO` и `CONTACTS_INFO` и замените на данные вашей школы:

```python
CONTACTS_INFO = """
📞 *Контакты Ваша Школа*

📱 Телефон: +7 (xxx) xxx-xx-xx
📍 Адрес: ваш адрес
...
"""
```

### Изменить название школы

Найдите все упоминания `Lingo School` в `bot.py` (поиск по Ctrl+H в редакторе) и замените на название вашей школы.
